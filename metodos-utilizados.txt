MÉTODOS UTILIZADOS – PESQUISA NO BACKEND

1. ClienteController::pesquisar()
   - Recebe o termo de pesquisa para clientes.
   - Encaminha a operação para ClienteDAO::pesquisarPorNome().

2. FornecedorController::pesquisar()
   - Recebe o termo de pesquisa para fornecedores.
   - Encaminha a operação para FornecedorDAO::pesquisarPorRazaoSocial().

3. ClienteDAO::pesquisarPorNome()
   - Executa SELECT id, nome, email, telefone FROM cliente.
   - Usa WHERE nome LIKE :nome para localizar parte ou todo o nome.
   - Usa prepared statement e bindValue() para evitar SQL Injection.
   - Adiciona os curingas % ao termo recebido.
   - Ordena os resultados por nome.

4. FornecedorDAO::pesquisarPorRazaoSocial()
   - Executa SELECT id, razao_social, email, telefone FROM fornecedor.
   - Usa WHERE razao_social LIKE :razao_social para localizar parte ou toda a razão social.
   - Usa prepared statement e bindValue() para evitar SQL Injection.
   - Adiciona os curingas % ao termo recebido.
   - Ordena os resultados por razão social.

5. fetchAll(PDO::FETCH_ASSOC)
   - Converte os resultados das consultas em arrays associativos.

6. trim()
   - Remove espaços extras do termo antes da consulta.

FLUXO DO BACKEND:
1. A camada de apresentação envia o termo para o controller correspondente.
2. O controller chama o método de pesquisa do DAO.
3. O DAO executa a consulta SQL parametrizada com LIKE.
4. Os registros encontrados são retornados ordenados para a camada de apresentação.
